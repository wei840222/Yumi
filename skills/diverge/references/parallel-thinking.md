# Parallel Thinking Reference

Six Thinking Hats is a parallel-thinking framework developed by Edward de Bono. It separates discussion into six thinking roles so a group can direct attention to facts, benefits, risks, feelings, creativity, and process control in turn.

Use this reference when a task benefits from deliberate role selection. Choose perspectives that fit the decision; this skill does not require a fixed six-role set.

Source: [De Bono Group, Six Thinking Hats](https://www.debonogroup.com/services/core-programs/six-thinking-hats/).
